# Read the context, retain the words

Authority: the user's next-TODO request, AGENTS.md, original HOW/similarities
examples and contextual reasoning nests. The syntax lab recommends named readers
over comma-count heuristics. This increment delivers that bounded inspection
prototype; portable schemas, versioning and machine interchange remain proposals.

1. Serve someone keeping useful context in a note: they should read a group of
   names or a complete explanation, then find its exact original words without
   learning a metadata language or losing their place.
2. Open Inspect reasoning / Ctrl+Space. A similarities note shows its written
   items in order; HOW retains its full prose. Raw fields switches the reading
   to the original hook/line fields. Select a listed item to edit its exact range;
   Return/Escape preserves the established source-edit and navigation behavior.
3. Deepen `// similarities ; AI ;; claudecode, claude, codex //` beside
   `// HOW ; codex, claude ;; I want either installer, if it is correct. //`.
   Unknown note kinds and annotated flush-left nests retain their original fields.
4. Alternatives: leave every payload as an undifferentiated string; infer arrays
   from punctuation everywhere; or expose explicitly named read-only readings
   alongside raw fields. Choose the third. This is an inspection choice with
   exact source navigation, not a source rewrite or an operation binding.
5. Match only the complete HOW and similarities heads, case-insensitively.
   HOW's inline payload is one explanation. Similarities splits an inline payload
   only at commas outside existing quoted spans. For an expanded similarities
   nest, each authored entry is one item; internal commas remain in that entry.
   Preserve order, duplicates, raw quotes, separator spans, annotations, source
   positions and unknown kinds. Named targets remain raw and unresolved. A
   listed group is an author's statement, not verified application evidence.
6. Challenge missing closers, open quotes, empty places, final commas, duplicate
   names, quoted commas, ordinary prose and stale item clicks. Expose reader
   issues locally without turning valid personal notes into parser errors.
   Pending edits keep their existing choices; a reader does not override them.
7. Deliver a shared context-reading projection, native reading/raw-field switch
   and exact item selection, CLI/MER integration and a bundled notes-only example.
   HOW nests stay written entries: no unexplained flattening into prose. Unknown
   schemas remain readable. Cross-note resolution and export remain later work.
8. Inspect wide/narrow native and MER views, including unfinished cases. Verify
   raw ranges and operation independence, native Undo/return/stale selection,
   repeated visits and source-only publishing. Keep visual evidence distinct
   from OS input/accessibility and human usability evidence.

## Implemented behavior

`ContextReading` retains its source document, owner and raw header. Items expose
their exact value and source spans, separator spans, line numbers and original
annotations. Inline commas inside existing quoted spans stay with those words;
quotes are not decoded. Empty places remain zero-length editable ranges, and
duplicates have distinct positions. HOW nests stay authored entries rather than
being concatenated into prose. Unknown, quoted or extended heads select Written.

Reader issues are local data, separate from parser diagnostics and execution
eligibility. An unknown personal note needs no registered schema. Targets stay
names as written; similarities records what the author listed together without
claiming independent application evidence.

Expanded entry parsing already retains a final comma separately, including one
inside an unfinished quote. The similarities reading conservatively rejoins that
source range for display and selection. It keeps the original parser fields on
the owner; Raw fields shows those unchanged fields. This does not silently repair
the quote or redefine the parser's unfinished-buffer grammar.

The native inspector uses the existing anchored return, source editor and save
flow. Item and field actions reject replaced owners or pending proposals. A stale
Raw fields action cannot reopen inspection during Apply/Leave. Reading and raw
view changes do not modify source or add Undo entries. New source documents reset
the inspection. CLI `inspect --at` and MER `structure` share the same reading;
the raw source remains present in both. The shipped example is
`src/Dert.Cli/Examples/context-notes.DERT`.
